# Submission Checklist

- [ ] Ensure `DEMO_SCRIPT.md` is ready and rehearsed.
- [ ] Record the 2-3 minute loom/YouTube demo.
- [ ] Upload the demo video to YouTube (Unlisted or Public).
- [ ] Verify that there are absolutely no secrets, API keys, or `.env` files committed to Git.
- [ ] Verify the GitHub repository is public (or accessible to reviewers).
- [ ] Fill out the Google Form submission with the YouTube link and the GitHub repository link.
- [ ] Ensure all code changes are pushed to `main`.
- [ ] Ensure `example_essay_output.md` is provided in the repository (or clearly shown).
