# Agent Logs — AI-Assisted Development

This folder records all AI-assisted development decisions, failed attempts, and fixes throughout the project.

## Files

| File | Purpose |
|------|---------|
| `decisions.md` | Key architecture and design decisions made with AI assistance |
| `failures.md` | Failed attempts, error logs, and how they were resolved |
| `session-log.md` | Chronological log of each AI-assisted development session |

## Guidelines

- Log every significant decision and the reasoning behind it
- Record failures honestly — they demonstrate learning and judgment
- Include timestamps for traceability
- **Remove all secrets and sensitive data before committing**
- Keep entries concise but informative

## Format

Each entry should follow this template:

```
### [Date] — [Brief Title]

**Context:** What was being attempted  
**Decision/Issue:** What was decided or what went wrong  
**Reasoning:** Why this approach was chosen or what caused the failure  
**Resolution:** How it was fixed (if applicable)  
**AI Tool Used:** Which AI tool assisted  
```
